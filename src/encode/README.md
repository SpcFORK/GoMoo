# Encode Directory Package

This directory contains the encoding utilities used for various data manipulation tasks, including but not limited to encoding and decoding Uint8 arrays with custom encoding schemes.

## Overview

- `muint8/`: Contains modules for encoding and decoding multi-utility Uint8 arrays.
- `blocks/`: Houses basic building blocks for encoding schemes, such as `UInt8E` for Uint8 array encoding and decoding.
- `bullpress/`: An encoder and compression for strings.
